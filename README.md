## 目录

```
app/                 网页 App（纯静态文件，不需要打包）
  index.html
  css/app.css
  js/main.js         入口与路由
  js/db.js           本地数据库（IndexedDB，软删除，为同步包合并做准备）
  js/i18n.js         中英文界面文字
  js/templates.js    品类模板（家具/电器/灯具/通用）
  js/photo.js        照片压缩、读取拍摄时间
  js/export-excel.js 导出总采购表（ExcelJS，嵌图）
  js/views/          各页面
  vendor/            第三方库（ExcelJS 4.4.0、exifr 7.1.3，MIT 许可）
```

## 正式网址

```bash
sh deploy.sh
```

## 在电脑上运行

```bash
python serve.py
```

（不要用 `python -m http.server`：它不禁止缓存，手机会继续用旧版代码。）

然后在浏览器中打开 http://localhost:8765

## 在手机上试用（同一 Wi-Fi）

1. 电脑上执行上面的命令。
2. 查出电脑的局域网 IP（PowerShell 里运行 `ipconfig`，看 IPv4 地址，例如 192.168.1.20）。
3. 手机浏览器打开 `http://192.168.1.20:8765`。如果打不开，需要在 Windows 防火墙里允许 Python 访问网络。

注意：数据按"网址"分开保存。用局域网地址测试时录入的数据，以后换成正式网址（Gitee Pages 等）后不会自动带过去。M2 的"导出/导入数据包"可以用来迁移。
